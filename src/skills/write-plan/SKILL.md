# superSpec: Write Plan

将 spec 转换为详细实现计划，每个任务 2-5 分钟，禁止占位符。

## 使用时机

当你需要从 spec 生成实现计划时，使用此技能。

## 强制清单

<EXTREMELY-IMPORTANT>
你必须按顺序完成以下步骤，不可跳过。
</EXTREMELY-IMPORTANT>

1. **声明使用技能**：告诉用户"我正在使用 write-plan 技能创建实现计划"
2. **读取 spec**：读取 `.superspec/specs/<name>/spec.md` 获取需求
3. **范围检查**：如果 spec 覆盖多个独立子系统，建议拆分为多个计划
4. **定义文件结构**：列出所有要创建/修改的文件及职责
5. **拆分任务**：每个任务 2-5 分钟，包含完整代码
6. **嵌入图表**：使用图表集成器在计划中嵌入依赖关系图，展示各任务之间的前后依赖关系和关键路径
7. **保存计划**：写入 `.superspec/plans/<name>.md`
8. **自检**：覆盖率、占位符、类型一致性
9. **审查**：派发审查子代理检查计划完整性

## 禁止占位符

<HARD-GATE>
计划中禁止出现以下模式，发现即为计划缺陷，必须修正：

- "TODO"、"TBD"、"implement later"
- "类似任务 N"（必须写完整代码）
- "添加适当的错误处理"（必须写具体代码）
- "Write tests for above code"（必须写具体测试代码）
- 没有代码块的代码步骤
- 引用未在任何任务中定义的类型/函数/方法
</HARD-GATE>

## 任务结构

每个任务必须包含：

```markdown
### 任务 N：<简短描述>

**文件**：<精确的文件路径>

**步骤**：

1. 编写失败测试
   ```typescript
   // 具体测试代码
   ```

2. 运行测试，确认失败
   ```bash
   npx vitest run test/xxx.test.ts
   # 预期输出：1 failed
   ```

3. 编写实现
   ```typescript
   // 具体实现代码
   ```

4. 运行测试，确认通过
   ```bash
   npx vitest run test/xxx.test.ts
   # 预期输出：1 passed
   ```

5. 提交
   ```bash
   git add -A && git commit -m "feat: <具体描述>"
   ```
```

## 自检清单

<EXTREMELY-IMPORTANT>
在提交计划前，必须完成以下自检：
</EXTREMELY-IMPORTANT>

- [ ] **spec 覆盖率**：每个 spec 需求都有对应任务
- [ ] **占位符扫描**：搜索 "TODO"、"TBD"、"implement later"、"类似任务"
- [ ] **类型一致性**：方法签名、属性名、类型名跨任务一致

## 跳步红线

| 跳步借口 | 现实 |
|----------|------|
| "计划太详细会很慢" | 没有细节的计划会导致返工，更慢 |
| "TODO 后面再填" | TODO 是计划缺陷，不是占位符 |
| "类似的任务可以省略" | 工程师可能不按顺序阅读，每个任务必须完整 |
| "这个很简单不需要计划" | 简单任务也有边界条件 |
| "我已经有思路了" | 有思路不等于计划完整 |
| "风险评估太麻烦，先写计划" | 没有风险评估的计划会遗漏关键路径 |
| "依赖关系不重要" | 依赖关系决定了执行顺序和并行度 |

## 完成检查清单

- [ ] 每个 spec 需求都有对应任务
- [ ] 没有 TODO/TBD/implement later 占位符
- [ ] 每个任务包含完整代码（测试 + 实现）
- [ ] 类型、命名跨任务一致
- [ ] 任务之间的依赖关系已标注
- [ ] 包含风险评估和缓解措施
- [ ] 图表已嵌入计划中
- [ ] 审查子代理已派发并通过

## 审查子代理

计划生成后，派发审查子代理检查：

1. **覆盖率**：每个 spec 需求是否被覆盖
2. **依赖**：任务之间是否有依赖问题
3. **边界**：是否遗漏边界情况
4. **一致性**：类型、命名是否跨任务一致

## 产出

计划文件格式：

```markdown
# <功能名称> 实现计划

> 生成时间：<日期>
> 来源 spec：<spec 路径>

## 文件结构

| 文件 | 职责 |
|------|------|
| src/xxx.ts | ... |
| test/xxx.test.ts | ... |

## 任务列表

### 任务 1：...
（具体内容）

### 任务 2：...
（具体内容）
```
